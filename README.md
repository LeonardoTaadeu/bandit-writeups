# OverTheWire Bandit Writeups

My journey through the [OverTheWire Bandit](https://overthewire.org/wargames/bandit/) wargame, documented level by level in English and Portuguese.

**Live site:** [https://SEU-USUARIO.github.io/bandit-writeups/](https://leonardotaadeu.github.io/bandit-writeups/)

## About this project

I'm building my foundation to work in penetration testing. Bandit teaches Linux and investigative thinking from the ground up, and I'm using it to practice something every pentester needs: explaining clearly what was done, how, and why.

This is not a list of answers. Each writeup focuses on the method behind the solution.

## What each writeup covers

- **Goal:** what the level asks, in my own words
- **How I solved it:** the commands I used and the reason behind each one
- **Where I got stuck:** the mistakes I made and how I worked through them
- **What I learned:** the concept behind the level and where it shows up in real security work
- **Video:** a walkthrough of the solution

## Tools and concepts covered

Linux command line, file permissions, SUID binaries, SSH key authentication, networking with `nc` and `openssl`, port scanning with `nmap`, cron jobs, and more as I progress.
